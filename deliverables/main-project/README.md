# Wisper-Alpha Main Delivery Package

This package is the GitHub-ready documentation baseline for the full 3-part project.

## Delivery structure (high + low levels)

### High level

1. Web app and backend integration
2. Tools orchestration and automation
3. Database/dashboard/final reporting

### Low level

| Part | Source location in repository | Main purpose |
|---|---|---|
| Part 1 | `parts/part-1-web-app-backend-integration` | API + web app runtime and backend unit tests |
| Part 2 | `parts/part-2-tools-reports-automation` | Terminal recon flow orchestrator (`wisper.sh`) |
| Part 3 | `parts/part-3-database-dashboard-final-report` | Data/reporting structure and final report artifacts |
