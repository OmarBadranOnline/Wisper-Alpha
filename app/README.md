# Part 1 - Web App and Backend Integration

This folder contains the planning baseline to execute **Part 1** of the project.

## Planning Files

1. `01-scope-and-deliverables.md` - scope boundaries, required outcomes, and acceptance.
2. `02-technical-structure.md` - proposed frontend/backend/shared structure and integration flow.
3. `03-execution-plan.md` - ordered tasks (P1-T01 to P1-T10), dependencies, and output of each task.
4. `04-api-ui-contract-plan.md` - initial API contracts and UI route mapping.

## Part 1 Goal

Deliver a usable web app connected to backend APIs for:

- target and session management,
- recon run initiation and run status tracking,
- a stable frontend shell and navigation,
- consistent request/error handling ready for Part 2 and Part 3.
